Route driver application

A compost hauler ran its routes off a printed spreadsheet. I built a progressive web app that reads that same sheet live — drivers work from their phones, the office watches progress arrive, and nobody had to learn a new system. Turn-by-turn navigation, notes and photos back from the cab, an approval queue for customer requests, and a server that physically cannot show a driver the billing columns.

Node · Express · WebSockets · Google Sheets API · vanilla JS · in daily use Try the walkthrough → Design tool

Golden Section Palette

A colour wheel and a palette generator built on the OKLCH colour space, where perceptual lightness is even across hues — so a palette holds its contrast ratios on every pairing instead of passing on some and quietly failing on others. Exports straight to CSS custom properties.

OKLCH · golden-ratio harmonies · no dependencies Open the tool → Client-facing tool

Site style control panel

Built into an interiors studio's site so the client could re-tone the whole thing herself. Pick a base colour and a harmony — complementary, analogous, split, triadic, monochrome — and every page re-derives from it in OKLCH, so contrast holds instead of breaking on one unlucky pairing. Try it freely: it saves to your own browser only, so nothing you change is visible to anyone else.

OKLCH · 7 harmony schemes · no framework, no build step Change the colours → Experiment

Resonance Engine

Musical, brainwave, colour and cymatic frequencies mapped against each other in one interface, with additive synthesis through the Web Audio API and a live canvas visualisation. Built because I wanted to see whether the correspondences held up.

How I work

HTML and CSS first

Structure and styling in markup, JavaScript only where it genuinely adds behaviour. Lightweight sites stay fast, and they stay maintainable long after launch.

Accessible by construction

WCAG 2.1 AA built in from the design stage — real contrast, real keyboard support, real screen-reader testing. Never an overlay widget.

Built to hand over

No proprietary framework, no page-builder lock-in. You own the code, the accounts and the documentation — so you are never stuck with any one developer, including me.
